# Media

Where the README's GIFs go. Two slots, referenced from the top of `README.md`:

| file | what it should show |
|---|---|
| `demo-hands.gif` | a hand driving instanced geometry, with the CHOP viewer visible alongside so the channels and the motion are in the same frame. ~12 s loop. |
| `demo-depth.gif` | the person mask and the depth map side by side, someone walking toward the camera so the depth actually changes. |

**Keep them under about 5 MB each.** A README that takes ten seconds to paint
reads as abandoned.

**The fixture privacy rule applies here too.** Body, clothing and room identify
someone perfectly well without a face in shot. Hands-only for anything committed,
and look at the frames before you commit them.
